# Market Basket Analysis

This project performs Market Basket Analysis (Association Rule Mining) on retail transaction data to discover interesting associations and relationships between products.

## Features
- **Data Preprocessing**: Cleaning and preparing transaction data.
- **Frequent Itemset Generation**: Using algorithms like Apriori, FP-Growth, or ECLAT.
- **Association Rule Mining**: Generating rules with metrics like Support, Confidence, Lift, and Conviction.
- **Interactive Visualization**: Visualizing itemsets, rules, and network graphs of product associations.
